# Astronomical Events

## Descrição

O objetivo deste projeto é criar uma aplicação que exibe duas listas de chuvas de meteoros. São elas:

- **Chuvas visíveis hoje**
- **Chuvas visíveis nos próximos 2 meses**

## Estrutura de Pastas

O projeto está organizado da seguinte forma:

```plaintext
.
├── data/
│   └── (Dados utilizados no projeto)
├── eventos-astronomicos/
│   └── (Código principal do projeto)
├── functions/
│   └── (Funções auxiliares)
├── README.md
├── app.js
└── package.json
```

## Como Executar

Clone o repositório:

```bash
[git clone <URL_DO_REPOSITORIO>](https://github.com/ifatinha/astronomical-events.git)
```

Instale as depências

  ```bash
  npm install
  ```

Execute a aplicação:

  ```bash
  node app.js
  ```
Acesse a aplicação no navegador para visualizar as listas de chuvas de meteoros.

## Tecnologias Utilizadas

- **Node.js**
- **JavaScript (ES6)**
- **JSON**

## Funcionalidades

- **Exibir Chuvas Visíveis Hoje**: Uma lista das chuvas de meteoros que podem ser vistas na data atual.
- **Exibir Chuvas nos Próximos 2 Meses**: Uma lista das chuvas de meteoros previstas para os próximos dois meses.
